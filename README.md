# aroma-redesign

Доработка дизайна демонстрационного сайта аромапродукции «Орлан».
Форк текущей версии с https://pizko.github.io/aroma/ — исходный сайт не изменяется.

## Что изменено

**Типографика**
- Подключены настоящие шрифты: `Prata` (заголовки) и `Golos Text` (текст). Раньше использовался системный стек, из-за чего сайт выглядел по-разному на macOS и Windows.
- Убран отрицательный трекинг заголовков (`-0.045em` → `-0.005em`).
- Мелкие подписи переведены с курсива на гротеск: у Prata нет курсивного начертания.

**Изображения**
- У трёх фотографий продукции вырезан белый фон (`assets/*-cut.png`), чтобы товар не лежал белым прямоугольником на цветной плашке.
- `opt-hero.jpg` обрезан: в левой части кадра была чужая рекламная вёрстка с крупной цифрой.

**Структура**
- Убрана нумерация `01/02/03` там, где порядка нет: направления, плитка каталога, услуги ателье, префиксы брендов. Оставлена там, где это реальная последовательность шагов.
- Диагональные стрелки `↗` заменены на `→`.
- Порог сворачивания навигации в «Меню» сдвинут с 1100px на 1000px.

**Анимации**
- Одна кривая `cubic-bezier(.16,1,.3,1)` и две длительности: `1.1s` на появление, `0.7s` на наведение.
- Изображения открываются срезом `clip-path` снизу вверх с одновременным `scale(1.06 → 1.0)`.
- Первый экран получил собственный каскад появления с шагом 80ms.
- Шапка уплотняет фон переходом при скролле.
- Всё отключается при `prefers-reduced-motion`.

Палитра (`--wine`, `--brass`, `--ivory`, `--paper`) оставлена без изменений.

## Что ещё требуется

- Оригиналы фотографий в полном разрешении: сейчас на весь сайт 7 уникальных кадров, часть повторяется, главный — 561×330.
- Интерьерные кадры продукции, а не только пэкшоты на белом фоне.
- Вычитка текстов.

## Запуск

```
python3 -m http.server 8731
```

Затем открыть http://localhost:8731/

## Права на контент

Фотографии продукции принадлежат поставщику и используются с его разрешения.

## Индексация

Демонстрационная версия закрыта от поисковых систем: `noindex,nofollow` на всех страницах
плюс `robots.txt`. Иначе в индексе оказались бы два почти одинаковых сайта.

Чтобы открыть индексацию после согласования: заменить `noindex,nofollow` на `index,follow`
в четырёх HTML-файлах и удалить `Disallow: /` из `robots.txt`.

  коротким описанием и переходом на свою страницу.

**Каталог**
- Фильтр по бренду (Stoneglow / Whispy) рядом с фильтром по категориям, поиск по каталогу,
  счётчик найденного и состояние «ничего не найдено».
- У карточек появились `data-brand` и `data-search` — по ним работает фильтрация и поиск.

**СТМ и ателье**
- На `private-label.html` добавлен редакционный разворот «Что входит в проект»: крупное фото
  коллекции Whispy и четыре пункта, собранные из уже подтверждённого содержания страницы.
- На `fragrance.html` добавлен редакционный ввод крупной типографикой.

**SEO**
- Хлебные крошки и `BreadcrumbList` на трёх внутренних страницах. URL не менялись.

**Чего сознательно не делал**
- Не создавал страницы отдельных товаров: в проекте нет подтверждённых характеристик, цен,
  объёмов и артикулов — только категории. Страницы получились бы пустыми, а `Product` JSON-LD
  пришлось бы выдумывать. Нужны данные от поставщика.
- Не трогал папку `v2/` (каркас на Astro с отдельной цветовой темой для каждой страницы):
  она не опубликована и противоречит правилу «не вводить полноэкранную тему для страницы».

**Что проверено**
- Фильтры, бренды, поиск, счётчик и пустое состояние — прогнаны в браузере на всех шести
  карточках.
- Переключение направлений касанием — проверено при эмуляции сенсорного экрана 390px.
- Все четыре страницы на 390px: `scrollWidth` = 390, наложений нет, битых картинок нет.
- Консоль: ошибок нет, все запросы 200.
- Анкета открывается, подставляет тему запроса, закрывается; ложного «заявка отправлена»
  на сайте нет — письмо по-прежнему готовится в почтовой программе.
